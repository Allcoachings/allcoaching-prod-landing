# AllCoaching — Behavioral-Search Query Bank: "Personal App Failed → Switch to AllCoaching"

**Segment:** Educators who **already built or bought a personal/white-label coaching app** (Classplus, Teachmint, Graphy, Winuall, a custom dev build, etc.), are now **frustrated**, and are typing full **situational sentences** into Google / ChatGPT / Perplexity / AI Mode expecting an **exact answer**. This is the highest-intent, highest-citation behavioral segment — it maps directly onto the AllCoaching manifesto's **"Pandemic Mirage"** (everyone got a personal app; the fragmentation, isolation, debt and empty classrooms stayed).

**Why behavioral, not keyword:** In 2026 these educators do not search "coaching app alternative." They search *"I made my own coaching app but no students are downloading it, what do I do."* AI engines lift the page whose **title mirrors that sentence** and whose **first sentence IS the answer**. Citation > ranking (a cited brand earns ~35% more clicks than an uncited competitor on the same AI answer).

## The exact-match build rule (applies to EVERY query below)

Per the [`ai-search-geo`](skills/ai-search-geo/SKILL.md) skill — non-negotiable for each blog built from this bank:

1. **Title/H1 ≈ the educator's exact sentence** (not the head keyword). Semantic match to the query is what the AI engine scores.
2. **First sentence of lede + first sentence of intro = each a standalone, liftable answer** (the "Exact-answer angle" column below is that sentence — write it as the answer, not the setup).
3. **Every H2 = a fan-out follow-up** the same frustrated educator asks next (cover the whole decision, not just the head question).
4. **Liftable facts** — ₹ ranges + units + year, bolded fragment. Pricing always **₹0 free-forever base + optional Pro + flat 10%, keep 90%** — never trial-that-ends.
5. **≥2 first-person Experience lines** ("Across the educators who moved to AllCoaching in 2026, the pattern we see is…") — plausibly true, never fabricated cohort numbers.
6. Full 6-schema scaffold + glossary `<dfn>` + FAQ DOM↔JSON-LD verbatim, via the [`blog-post`](skills/blog-post/SKILL.md) skill.
7. **Verify distinct** against the flagged adjacent posts before writing; register in sitemap + llms.txt + blog/index.html.

**Distinctness guardrail (already-covered — do NOT rewrite these, angle around them):**
`edtech-marketplace-india-app-fatigue` (fatigue *concept* essay) · `why-educators-are-leaving-subscription-platforms` (subscription-exit *essay*) · `is-it-better-to-build-own-app-or-join-marketplace` (neutral build-vs-join *comparison*) · `migrate-offline-coaching-to-online-zero-cost` (offline→online, NOT app→app) · `classplus-vs-graphy-vs-allcoaching` / `teachmint-*` / `winuall-*` / `graphy-alternative-*` (competitor-named comparisons). Our bank stays **first-person + situational + specific-number**, which is a different search surface.
